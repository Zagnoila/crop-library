How to install & use this library

This website is an interactive preview. Its saved notes stay in this browser and are separate from the extension.

  1. Download and unzip the extension files.
  2. In Chrome, type chrome://extensions in the address bar. Turn on Developer mode.
  3. Click Load unpacked and select the extracted folder containing manifest.json.
  4. Open Crop Library from the extensions menu. Save a note, close it, then reopen to find the note again.

Export downloads all your notes as a JSON file, a readable backup of your research. Local notes are not automatically synced between devices. Uninstalling the extension or clearing site data can remove them.
